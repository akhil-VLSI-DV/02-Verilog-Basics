# Verilog Basics

Basic Verilog HDL implementations and testbenches for fundamental digital logic gates.

## Gates Implemented

- AND
- OR
- NOT
- NAND
- NOR
- XOR
- XNOR

## Tools

- Verilog HDL
- EDA Playground
- GitHub

## Verification

Each gate is tested using a Verilog testbench with all possible input combinations.
